# Sorpresa estilo código con girasoles 🌻

## Qué incluye
- `index.html`: página completa, lista para GitHub Pages.
- No necesita fotos.
- No necesita música.
- No usa librerías externas.

## Cómo personalizar rápido
Abre `index.html` y busca:

```js
const sorpresa = {
```

Ahí puedes cambiar:
- `nombre`
- `mensaje`
- `cierre`
- `firma`

## Cómo subirlo a GitHub
1. Entra a tu repositorio.
2. Reemplaza el `index.html` actual por este nuevo.
3. Haz commit.
4. Espera unos segundos y abre tu GitHub Pages.
